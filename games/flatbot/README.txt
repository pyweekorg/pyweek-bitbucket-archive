Flat Bot
========

Entry in PyWeek #5  <http://www.pyweek.org/5/>
Team: flatbot
Members: Richard Jones


Clearly this game isn't finished. It only has one level and it's not
particularly challenging. There is scope for adding in more challenges
and harder levels.


DEPENDENCIES:

You will need:

  AVBin:                   http://code.google.com/p/avbin/
  Python 2.5:              http://www.python.org/
  *or*
  Python 2.4 with ctypes:  http://pypi.python.org/pypi/ctypes


RUNNING THE GAME:

On Windows or Mac OS X, locate the "run_game.pyw" file and double-click it.

Othewise open a terminal / console and "cd" to the game directory and run:

  python run_game.py



HOW TO PLAY THE GAME:

Move around using the cursor keys. Kick the football to the far end of the
level where your friend is waiting.

Press UP to jump.

Press "Z" to zap your laser.
